# Body Master Gym Website

A modern, professional static website for Body Master Gym in Dubai.

## Features

✨ **Modern Design**
- Responsive layout that works on all devices
- Smooth animations and transitions
- Professional color scheme with red/black theme

🎨 **Sections Included**
- Hero section with full-screen image
- Animated statistics counter
- About Us with Mission, Vision, and Goals
- Why Choose Us with 4 main features
- Services showcase
- Pricing plans (6 membership options)
- Gallery with lightbox effect
- Testimonials slider
- Contact form with Google Maps
- Professional footer

💪 **Interactive Features**
- Sticky navigation bar with scroll effect
- Dropdown menu for services
- Subscription modal with WhatsApp integration
- Contact form with WhatsApp integration
- Gallery lightbox for image viewing
- Testimonials auto-slider
- Scroll to top button
- Smooth scrolling navigation

📱 **Technologies Used**
- HTML5
- CSS3 with modern animations
- JavaScript (Vanilla)
- Bootstrap 5.3
- Font Awesome 6.4
- AOS (Animate On Scroll)
- Google Fonts (Poppins)

## How to Use

1. Open `index.html` in your browser
2. All images should be in the `images/` folder
3. The website is fully responsive and works on mobile, tablet, and desktop

To add more images to the gallery:
1. Add images to the `images/` folder
2. Update the gallery section in `index.html`
3. The lightbox will work automatically
